# Directorate of IT — Pakistan Railways

Responsive static website for the Directorate of IT, Pakistan Railways.

## Open in VS Code
1. Extract this ZIP.
2. Open the Pakistan-Railways-IT-Website folder in VS Code (File > Open Folder).
3. Install the Live Server extension.
4. Right-click dist/index.html and choose Open with Live Server.

No npm installation or build step is required.

## Files
- dist/index.html: page content and sections
- dist/style.css: base styles and section design
- dist/responsive.css: responsive layouts, including the hero
- dist/director.css: director portrait styling
- dist/footer.css: footer layout and styling
- dist/animations.css: scroll reveals and hover animations
- dist/app.js: navigation, filtering, scroll animations and enquiry form
- dist/assets/: logo and images
- dist/projects.json: project data reference

The enquiry form opens the visitor's email app; it does not send email through a backend. Social icons link to the Directorate's official accounts.
Local edits do not automatically update the hosted website.
